# DDL 操作

## 概述

Firebird 支持标准 DDL（数据定义语言）操作，用于模式管理。本节介绍 Firebird 特定功能的表创建、修改和删除。

## 支持的操作

### CREATE TABLE

```python
# 基本表创建
backend.execute("""
    CREATE TABLE users (
        id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        username VARCHAR(50) NOT NULL,
        email VARCHAR(255) NOT NULL,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    )
""")

# 带 BLOB 列的表
backend.execute("""
    CREATE TABLE documents (
        id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        title VARCHAR(255) NOT NULL,
        content BLOB SUB_TYPE TEXT SEGMENT SIZE 16384 CHARACTER SET UTF8,
        binary_data BLOB SUB_TYPE 0 SEGMENT SIZE 65536
    )
""")

# 带数组列的表
backend.execute("""
    CREATE TABLE tags (
        id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        name VARCHAR(50) NOT NULL,
        values INTEGER[10]
    )
""")
```

### ALTER TABLE

```python
# 添加列
backend.execute("ALTER TABLE users ADD COLUMN phone VARCHAR(20)")

# 修改列
backend.execute("ALTER TABLE users ALTER COLUMN phone TO telephone")

# 删除列
backend.execute("ALTER TABLE users DROP COLUMN telephone")

# 添加约束
backend.execute("ALTER TABLE users ADD CONSTRAINT uk_users_email UNIQUE (email)")

# 删除约束
backend.execute("ALTER TABLE users DROP CONSTRAINT uk_users_email")
```

### DROP TABLE

```python
# 删除表
backend.execute("DROP TABLE users")

# 如果存在则删除表
backend.execute("DROP TABLE IF EXISTS users")
```

## Firebird 特定 DDL 功能

### 域

创建可重用的列类型定义：

```python
# 创建域
backend.execute("""
    CREATE DOMAIN EMAIL_ADDRESS AS VARCHAR(255)
    NOT NULL
    CHECK (VALUE LIKE '%@%.%')
""")

# 在表中使用域
backend.execute("""
    CREATE TABLE users (
        id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        email EMAIL_ADDRESS NOT NULL
    )
""")

# 删除域
backend.execute("DROP DOMAIN EMAIL_ADDRESS")
```

### 生成器（序列）

Firebird 使用生成器进行序列管理：

```python
# 创建生成器
backend.execute("CREATE GENERATOR user_id_gen")

# 设置生成器值
backend.execute("SET GENERATOR user_id_gen TO 1000")

# 在表中使用生成器
backend.execute("""
    CREATE TABLE users (
        id INTEGER NOT NULL,
        name VARCHAR(50),
        CONSTRAINT pk_users PRIMARY KEY (id)
    )
""")

# 创建触发器以使用生成器
backend.execute("""
    CREATE TRIGGER trg_users_id FOR users
    ACTIVE BEFORE INSERT POSITION 0
    AS
    BEGIN
        NEW.id = GEN_ID(user_id_gen, 1);
    END
""")
```

### 存储过程

```python
# 创建存储过程
backend.execute("""
    CREATE PROCEDURE get_user_stats(IN user_id INTEGER)
    RETURNS (order_count INTEGER, total_spent DECIMAL(10,2))
    AS
    BEGIN
        SELECT COUNT(*), SUM(amount)
        INTO order_count, total_spent
        FROM orders
        WHERE user_id = :user_id;
        SUSPEND;
    END
""")

# 删除存储过程
backend.execute("DROP PROCEDURE get_user_stats")
```

### 触发器

```python
# 创建触发器
backend.execute("""
    CREATE TRIGGER trg_users_audit FOR users
    ACTIVE AFTER INSERT OR UPDATE OR DELETE POSITION 0
    AS
    BEGIN
        INSERT INTO audit_log (table_name, action, timestamp)
        VALUES ('users', 
                CASE 
                    WHEN INSERTING THEN 'INSERT'
                    WHEN UPDATING THEN 'UPDATE'
                    WHEN DELETING THEN 'DELETE'
                END,
                CURRENT_TIMESTAMP);
    END
""")

# 删除触发器
backend.execute("DROP TRIGGER trg_users_audit")
```

### 视图

```python
# 创建视图
backend.execute("""
    CREATE VIEW active_users AS
    SELECT id, username, email
    FROM users
    WHERE active = 1
""")

# 删除视图
backend.execute("DROP VIEW active_users")
```

## DDL 扩展

### 用于 DDL 的 EXECUTE BLOCK

使用 EXECUTE BLOCK 进行条件 DDL：

```python
backend.execute("""
    EXECUTE BLOCK AS
    BEGIN
        -- 如果不存在则创建表
        IF (NOT EXISTS (SELECT 1 FROM rdb$relations WHERE rdb$relation_name = 'USERS')) THEN
        BEGIN
            EXECUTE STATEMENT '
                CREATE TABLE users (
                    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
                    username VARCHAR(50) NOT NULL
                )';
        END
    END
""")
```

### 元数据查询

```python
# 列出所有表
tables = backend.execute("""
    SELECT rdb$relation_name 
    FROM rdb$relations 
    WHERE rdb$system_flag = 0
    ORDER BY rdb$relation_name
""")

# 获取表列
columns = backend.execute("""
    SELECT rdb$field_name, rdb$field_type, rdb$field_length
    FROM rdb$relation_fields rf
    JOIN rdb$fields f ON rf.rdb$field_source = f.rdb$field_name
    WHERE rf.rdb$relation_name = 'USERS'
    ORDER BY rf.rdb$field_position
""")
```
