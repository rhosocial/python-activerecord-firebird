# 支持的版本

## Firebird 版本

| 版本 | 支持级别 | 备注 |
|------|----------|------|
| 3.0+ | 完整 | 推荐用于生产环境 |
| 2.5+ | 部分 | 基本功能 |
| 2.1+ | 有限 | EXECUTE BLOCK、MERGE |
| 1.0+ | 遗留 | BLOB、域、序列 |

### 功能矩阵

| 功能 | 最低版本 | 备注 |
|------|----------|------|
| 基本操作 | 3.0+ | 核心功能 |
| BLOB 类型 | 1.0+ | 二进制/文本子类型 |
| 域 | 1.0+ | CREATE DOMAIN |
| 序列 | 1.0+ | 生成器 |
| 存储过程 | 1.0+ | PSQL |
| 外部函数 | 2.5+ | EXTERNAL FUNCTION |
| 窗口函数 | 3.0+ | ROW_NUMBER、RANK 等 |
| EXECUTE BLOCK | 2.1+ | 匿名 PSQL |
| MERGE 语句 | 2.1+ | 更新插入 |
| BOOLEAN 类型 | 3.0+ | 原生布尔 |
| 标识列 | 3.0+ | GENERATED BY DEFAULT AS IDENTITY |
| DBMS_OUTPUT | 2.1+ | 服务器端输出 |

## Python 版本

| 版本 | 支持级别 |
|------|----------|
| 3.11 | 完整 |
| 3.12 | 完整 |
| 3.13 | 完整 |
| 3.13t | 完整（自由线程） |
| 3.14 | 完整 |
| 3.14t | 完整（自由线程） |

## 依赖版本

| 包 | 所需版本 |
|----|----------|
| `rhosocial-activerecord` | >=1.0.0,<2.0.0 |
| `firebird-driver` | >=2.0.0 |
| `DBUtils`（可选） | >=3.0.0 |

## 安装

```bash
# 基本安装
pip install rhosocial-activerecord-firebird

# 支持池
pip install rhosocial-activerecord-firebird[pooling]

# 开发安装
pip install rhosocial-activerecord-firebird[dev,test]
```

## 推荐设置

为了获得最佳功能支持：

- **Firebird**: 3.0 或更高版本
- **Python**: 3.11 或更高版本
- **驱动程序**: firebird-driver 2.0+
