# 本地测试

## 概述

本节介绍使用 Docker 设置本地 Firebird 测试环境。

## Docker 设置

### docker-compose.yml

```yaml
version: '3.8'
services:
  firebird:
    image: jacobalberty/firebird:4.0
    environment:
      - FIREBIRD_DATABASE=test.fdb
      - FIREBIRD_USER=SYSDBA
      - FIREBIRD_PASSWORD=masterkey
      - FIREBIRDDebugEnabled=true
    ports:
      - "3050:3050"
    volumes:
      - firebird-data:/var/lib/firebird/4.0/data
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql

volumes:
  firebird-data:
```

### 启动服务器

```bash
# 启动 Firebird 服务器
docker-compose up -d

# 检查状态
docker-compose ps

# 查看日志
docker-compose logs -f firebird
```

### 停止服务器

```bash
# 停止服务器
docker-compose down

# 停止并删除卷
docker-compose down -v
```

## 故障排除

### 常见问题

1. **连接被拒绝**
   - 检查 Docker 容器是否运行
   - 验证端口映射

2. **数据库未找到**
   - 检查卷挂载
   - 验证数据库路径

3. **认证失败**
   - 检查用户名/密码
   - 验证用户权限

## 性能测试

### 基准测试

```python
import time

def benchmark_query(backend, iterations=1000):
    """基准测试查询性能。"""
    start_time = time.time()
    for i in range(iterations):
        backend.execute("SELECT 1 FROM rdb$database")
    end_time = time.time()
    print(f"平均查询时间: {(end_time - start_time) / iterations * 1000:.2f}ms")
```

### 负载测试

```python
from concurrent.futures import ThreadPoolExecutor

def load_test(backend, num_threads=10, queries_per_thread=100):
    """多线程负载测试。"""
    def worker():
        for i in range(queries_per_thread):
            backend.execute("SELECT 1 FROM rdb$database")
    
    with ThreadPoolExecutor(max_workers=num_threads) as executor:
        futures = [executor.submit(worker) for _ in range(num_threads)]
        for future in futures:
            future.result()
```

### 干净状态

```python
# 确保每个测试的干净状态
@pytest.fixture(autouse=True)
def clean_state(firebird_backend):
    firebird_backend.execute("DELETE FROM users")
    yield
    firebird_backend.execute("DELETE FROM users")
```
