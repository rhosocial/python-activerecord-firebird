# Supported Versions

## Firebird Versions

| Version | Support Level | Notes |
|---------|---------------|-------|
| 3.0+ | Full | Recommended for production |
| 2.5+ | Partial | Basic functionality |
| 2.1+ | Limited | EXECUTE BLOCK, MERGE |
| 1.0+ | Legacy | BLOB, Domains, Sequences |

### Feature Matrix

| Feature | Min Version | Notes |
|---------|-------------|-------|
| Basic operations | 3.0+ | Core functionality |
| BLOB types | 1.0+ | Binary/text subtypes |
| Domains | 1.0+ | CREATE DOMAIN |
| Sequences | 1.0+ | Generators |
| Stored procedures | 1.0+ | PSQL |
| External functions | 2.5+ | EXTERNAL FUNCTION |
| Window functions | 3.0+ | ROW_NUMBER, RANK, etc. |
| EXECUTE BLOCK | 2.1+ | Anonymous PSQL |
| MERGE statement | 2.1+ | Upsert |
| BOOLEAN type | 3.0+ | Native boolean |
| Identity columns | 3.0+ | GENERATED BY DEFAULT AS IDENTITY |
| DBMS_OUTPUT | 2.1+ | Server-side output |

## Python Versions

| Version | Support Level |
|---------|---------------|
| 3.11 | Full |
| 3.12 | Full |
| 3.13 | Full |
| 3.13t | Full (free-threaded) |
| 3.14 | Full |
| 3.14t | Full (free-threaded) |

## Dependency Versions

| Package | Required Version |
|---------|------------------|
| `rhosocial-activerecord` | >=1.0.0,<2.0.0 |
| `firebird-driver` | >=2.0.0 |
| `DBUtils` (optional) | >=3.0.0 |

## Installation

```bash
# Basic installation
pip install rhosocial-activerecord-firebird

# With pooling support
pip install rhosocial-activerecord-firebird[pooling]

# Development installation
pip install rhosocial-activerecord-firebird[dev,test]
```

## Recommended Setup

For optimal feature support:

- **Firebird**: 3.0 or later
- **Python**: 3.11 or later
- **Driver**: firebird-driver 2.0+
