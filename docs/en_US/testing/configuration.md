# Test Configuration

## Overview

This section covers Firebird-specific test setup and configuration.

## Test Database Setup

### Create Test Database

```bash
# Using isql
isql-fb -user SYSDBA -password masterkey
> CREATE DATABASE '/tmp/test_activerecord.fdb';
> EXIT;
```

### Docker Setup

```yaml
# docker-compose.yml
version: '3.8'
services:
  firebird:
    image: jacobalberty/firebird:4.0
    environment:
      - FIREBIRD_DATABASE=test.fdb
      - FIREBIRD_USER=SYSDBA
      - FIREBIRD_PASSWORD=masterkey
    ports:
      - "3050:3050"
    volumes:
      - firebird-data:/var/lib/firebird/4.0/data

volumes:
  firebird-data:
```

## Python Test Configuration

### conftest.py

```python
import pytest
from rhosocial.activerecord.backend.impl.firebird import FirebirdBackend
from rhosocial.activerecord.backend.impl.firebird.config import FirebirdConnectionConfig

@pytest.fixture(scope="session")
def firebird_config():
    """Firebird configuration for testing."""
    return FirebirdConnectionConfig(
        host="localhost",
        port=3050,
        database="/tmp/test_activerecord.fdb",
        username="SYSDBA",
        password="masterkey",
        charset="UTF8"
    )

@pytest.fixture(scope="session")
def firebird_backend(firebird_config):
    """Create and connect a Firebird backend for testing."""
    backend = FirebirdBackend(config=firebird_config)
    backend.connect()
    yield backend
    backend.disconnect()
```

### Test Fixtures

```python
@pytest.fixture(autouse=True)
def setup_teardown(firebird_backend):
    """Setup and teardown for each test."""
    # Setup
    firebird_backend.execute("""
        CREATE TABLE users (
            id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
            name VARCHAR(100) NOT NULL,
            email VARCHAR(255) NOT NULL,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )
    """)
    
    yield
    
    # Teardown
    firebird_backend.execute("DROP TABLE IF EXISTS users")
```

## Test Data

### Creating Test Data

```python
def create_test_data(backend):
    """Create test data for testing."""
    backend.execute("""
        INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com')
    """)
    backend.execute("""
```

### Cleaning Test Data

```python
def clean_test_data(backend):
    """Clean test data after testing."""
    backend.execute("DELETE FROM users")
```

## Best Practices

### Isolation

```python
# Each test should be independent
def test_user_creation(backend):
    backend.execute("INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com')")
    result = backend.execute("SELECT * FROM users WHERE name = 'Alice'")
    assert len(result) == 1
    # Cleanup
    backend.execute("DELETE FROM users WHERE name = 'Alice'")
```

### Serial Execution

```python
# Tests MUST run serially
# Do NOT use pytest -n auto
```

### Clean State

```python
# Ensure clean state for each test
@pytest.fixture(autouse=True)
def clean_state(firebird_backend):
    firebird_backend.execute("DELETE FROM users")
    yield
    firebird_backend.execute("DELETE FROM users")
```
