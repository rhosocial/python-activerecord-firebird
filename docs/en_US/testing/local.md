# Local Testing

## Overview

This section covers setting up a local Firebird test environment using Docker.

## Docker Setup

### docker-compose.yml

```yaml
version: '3.8'
services:
  firebird:
    image: jacobalberty/firebird:4.0
    environment:
      - FIREBIRD_DATABASE=test.fdb
      - FIREBIRD_USER=SYSDBA
      - FIREBIRD_PASSWORD=masterkey
      - FIREBIRDdığında=true
    ports:
      - "3050:3050"
    volumes:
      - firebird-data:/var/lib/firebird/4.0/data
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql

volumes:
  firebird-data:
```

### Start Server

```bash
# Start Firebird server
docker-compose up -d

# Check status
docker-compose ps

# View logs
docker-compose logs -f firebird
```

### Stop Server

```bash
# Stop server
docker-compose down

# Stop and remove volumes
docker-compose down -v
```

## Troubleshooting

### Common Issues

1. **Connection refused**
   - Check if Docker container is running
   - Verify port mapping

2. **Database not found**
   - Check volume mounting
   - Verify database path

3. **Authentication failed**
   - Check username/password
   - Verify user permissions

## Performance Testing

### Benchmark Tests

```python
import time

def benchmark_query(backend, iterations=1000):
    """Benchmark query performance."""
    start_time = time.time()
    for i in range(iterations):
        backend.execute("SELECT 1 FROM rdb$database")
    end_time = time.time()
    print(f"Average query time: {(end_time - start_time) / iterations * 1000:.2f}ms")
```

### Load Testing

```python
from concurrent.futures import ThreadPoolExecutor

def load_test(backend, num_threads=10, queries_per_thread=100):
    """Load test with multiple threads."""
    def worker():
        for i in range(queries_per_thread):
            backend.execute("SELECT 1 FROM rdb$database")
    
    with ThreadPoolExecutor(max_workers=num_threads) as executor:
        futures = [executor.submit(worker) for _ in range(num_threads)]
        for future in futures:
            future.result()
```

## Best Practices

### Use Docker for Isolation

```bash
# Use Docker for consistent test environment
docker-compose up -d
PYTHONPATH=src pytest tests/
docker-compose down
```

### Clean State

```python
# Ensure clean state for each test
@pytest.fixture(autouse=True)
def clean_state(firebird_backend):
    firebird_backend.execute("DELETE FROM users")
    yield
    firebird_backend.execute("DELETE FROM users")
```

### Serial Execution

```bash
# Tests MUST run serially
PYTHONPATH=src pytest tests/
# Do NOT use: pytest -n auto
```
