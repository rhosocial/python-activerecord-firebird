Add version-gated `CREATE TABLE ... AS` support: `supports_create_table_as` and `supports_with_data_clause` were measured on Firebird 5.0.4 and 6.0.0 (5.0.4 answers `Token unknown - AS` for both CTAS spellings; 6.0.0 creates and populates the table and accepts `WITH DATA` / `WITH NO DATA`) and are gated at Firebird 6, so Firebird 6 renders CTAS including the population clause while Firebird 5 refuses the statement by name instead of emitting SQL the server rejects.
