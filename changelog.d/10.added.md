The CLI now advertises thirty types, up from twenty-two. Five families -- `unused-indexes`, `table-stats`, `runtime`, `index-stats` and `ddl` -- refuse with exit 2, and `publications` is gated at Firebird 4. Storage is refused outright: `supports_table_storage_introspection` is `False` because `RDB$PAGES` describes the file rather than relations, the size slots stay `None`, and no CLI type offers it. Profiles, samples and coverage aggregate the rows, one wide row because union arms cannot share a bounds type; `opaque_columns` names BLOBs whose bounds stay `None`; `* 1.0` keeps integer division honest; and the row bound uses the dialect's own LIMIT renderer. `rdb-dependencies` replaces `dependencies` because core's path is unimplemented and `RDB$DEPENDENCIES` spells `RDB$DEPENDED_ON_NAME`. `_NAME_RULE` decides NAME once, so six families that previously ignored a name now refuse it with exit 2, and a new `docs/introspection.md` records each refusal with its cause.
